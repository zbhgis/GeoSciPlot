说明

· 上传的图片会立即写入 raw/；点发布后才会压缩出缩略图、更新索引并生成站点。
· 图片 id 由内容算出（sha1 前 10 位），与文件名无关 —— 重复上传同一张图会被识别出来。
· 若上传后不发布，图片仍留在 raw/，下次生成会以「未命名」收录，可在 meta/titles.csv 里补。
· 删除图片会同时移除缩略图、原图副本、raw/ 原图与索引条目，并同步 GitHub。
· 发布 = 写 meta/titles.csv → prepare.py → build_site.py → git add/commit/push →（可选）同步服务器。
