# 关于本站

GeoSciPlot 收录公开发表的地学 / 科研图表，供绘图风格与配色参考；
每张图附原始论文 DOI、标签与主色分析，可按颜色与标签检索。

图表版权归各原作者；站点为纯静态生成，代码与元数据开源于
[GitHub](https://github.com/zbhgis/GeoSciPlot)。

# 常见问题

## 图是从哪里来的？

全部来自公开发表的论文与出版物，由维护者逐张人工收录：取原图、核对出处、整理「范围 × 样式」标签并分析主色。每张图的详情页都附原始论文 DOI，点开即可溯源。

## 「范围」和「样式」标签是什么意思？

图库标签是双轨制。**范围**指图所覆盖的地理范围（全球陆地、北极、竖版中国地图等，固定枚举）；**样式**指绘图手法与风格（双变量、复杂组图等，持续扩充）。筛选时组内多选为「命中任一」、两组之间为「同时满足」，筛选结果可经 URL 直接分享给别人。

## 怎么按颜色找图？

每张图入库时自动分析主色，首页可用取色器按颜色筛选、并按与所选颜色的相近程度排序。想细抠配色可进[色彩实验](https://geosciplot.zbhgis.com/color-lab/)：框选任意图片统计主要颜色的色号，把指定颜色替换成新颜色试调，还能叠加红盲 / 绿盲 / 蓝盲视角模拟检查配色的可辨识度——全部在浏览器本地完成，结果图可下载。

## 找到合适的图，能直接用到自己的论文或报告里吗？

不建议直接搬运。图片版权归原论文作者与出版商，本站定位是绘图风格、配色与版式的**参考**。如确需复用，请遵循原论文的版权协议（必要时向出版商申请授权），并在引用处规范标注出处——DOI 就在详情页。

## 想看大图或下载原图？

详情页「查看原图」直链与灯箱放大取的都是未经改动的原始文件，更高分辨率请循 DOI 到原论文获取。

## 图片加载很慢或打不开？

图片不打包进站点，默认由 jsDelivr 与 GitHub raw 分发并逐图自动降级，这两个源在部分网络环境下可能不稳定；加载失败可稍后重试或更换网络。加载前页面会按真实比例显示占位层，不会抖动。

## 想推荐一张图？

欢迎。在 GitHub 仓库的 [Issues](https://github.com/zbhgis/GeoSciPlot/issues/new/choose) 选「**图片投稿**」模板：把图片拖进上传框（可多张），填 DOI（必填）、建议标签与一句说明，勾选版权确认后提交；维护者核对后录入图库，收录情况在该 issue 里回复。

## 我是图片版权人，想下架我的图？

在 GitHub 提 [issue](https://github.com/zbhgis/GeoSciPlot/issues/new/choose) 说明即可（附上对应图 id 或 DOI），核实后会尽快移除。

## 站点是开源的吗？

是。纯静态生成——本地脚本构建，无服务器端逻辑、无数据库；代码以 MIT 许可开源在 [GitHub](https://github.com/zbhgis/GeoSciPlot)，标签、主色与 DOI 索引等元数据随仓库分发。

## 「制图经验」是什么？

与图库并列的独立栏目，收录制图技巧与经验类文章，入口在顶部菜单。

# 一点说明

本站是个人维护的非营利参考项目，与所收录图表的作者及出版商无从属关系。标签、主色与页面说明都只是辅助检索的整理，难免有偏差——具体的配色、数据与结论，请一律回到原论文；图表能否取用，也以原论文的版权协议为准。发现错漏欢迎通过 [issue](https://github.com/zbhgis/GeoSciPlot/issues/new/choose) 指出，会尽快修正。
