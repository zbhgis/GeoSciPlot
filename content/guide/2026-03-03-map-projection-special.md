# 特殊地图投影汇总

以下地图投影比如Goode，Spilhaus，Orthographic这三类投影是比较特别的投影，其中Goode Homolosine投影是把海洋给切开，保证陆地的完整性；Spilhaus-Adams则相反，是突出海洋部分；Orthographic投影就是正射投影，但是角度不同投影结果也有很大差别；剩余的Gall-Peters，Lambert Cylindrical，Winkel Tripel和Wagner IV这四类投影用得比较少，但是在期刊中也有一小部分文章使用，和之前介绍的常用投影差别不大，就不再过多介绍。具体不同投影的差别可以在以下网站查询对比或者直接问AI大模型。

https://map-projections.net/projections-list.php

接下来是整理的7个特殊的或较少使用的全球地图投影（没有进行客观的数据统计，仅仅是结合经验和部分搜索结果得出）。

| 名称                                                  | 类型   | 属性 | 主要特点与用途                                   |
| ----------------------------------------------------- | ------ | ---- | ------------------------------------------------ |
| Goode/ Goode Homolosine                               | 伪圆柱 | 等积 | 突出陆地，减少扭曲，面积准确                     |
| Spilhaus-Adams / Spilhaus World Ocean Map in a Square | 多边形 | 折衷 | 突出海洋连续性，陆地压缩                         |
| Orthographic / Azimuthal                              | /      | /    | 太空视角，大多为半球视图或极地视图，三维地球感强 |
| Gall-Peters / Gall Orthographic / Peters projection   | 圆柱   | 等积 | 矩形地图，面积准确                               |
| Lambert Cylindrical / Lambert Cylindrical Equal Area  | 圆柱   | 等积 | 矩形呈现，面积准确                               |
| Winkel Tripel                                         | 伪圆柱 | 折衷 | 畸变低，保证视觉平衡                             |
| Wagner IV                                             | 伪圆柱 | 等积 | 经线椭圆弧，侧边平滑，面积精确                   |

# 不同投影的用途

Goode，Spilhaus，Orthographic这三类投影主要是展示数据的时候，用于突出全球视角下的某个特殊区位（陆地，海洋，或者指定区域），之后进行复现这三类地图投影时，就能感受到这些地图投影的不同；文中后四类投影均属于等面积投影，就不再展开。
