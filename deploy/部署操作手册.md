## 步骤 ④：DNS 子域解析【你来做】

阿里云控制台 → 云解析 DNS → zbhgis.com → 添加记录：

```
记录类型：A
主机记录：geosciplot
记录值：  47.98.133.104     （与你主站同一台 ECS）
TTL：     10 分钟
```

验证（本地 CMD/PowerShell）：`nslookup geosciplot.zbhgis.com` → 应返回 47.98.133.104。

## 步骤 ⑤：服务器上签证书 + 配 Nginx【你来做】

SSH 登录服务器（你平时的方式）后依次执行：

### 5.1 建 acme 验证目录
```bash
mkdir -p /var/www/acme/geosciplot
```

### 5.2 给子域签发证书（复用主站的 acme.sh 与 webroot）
```bash
acme.sh --issue -d geosciplot.zbhgis.com \
  --webroot /opt/mystation/frontend \
  --keylength ec-256
```
> 说明：验证请求打到 80 端口时由主站的 nginx 块兜底服务（webroot 在主站目录里），
> 与 deploy-https.sh 的主域签发方式一致。

### 5.3 安装证书（续期时自动 reload）
```bash
acme.sh --install-cert -d geosciplot.zbhgis.com --ecc \
  --cert-file      /etc/nginx/ssl/geosciplot.zbhgis.com.cer \
  --key-file       /etc/nginx/ssl/geosciplot.zbhgis.com.key \
  --fullchain-file /etc/nginx/ssl/geosciplot.zbhgis.com.fullchain.cer \
  --reloadcmd      "nginx -s reload"
```

### 5.4 部署 Nginx 配置
配置文件已在仓库里：`deploy/nginx-geosciplot.conf`（证书路径已对齐 5.3）。
把它上传到服务器（scp / 面板均可）后：

```bash
cp geosciplot.conf /etc/nginx/conf.d/geosciplot.conf
nginx -t && systemctl reload nginx
```

### 5.5 建站点目录
```bash
mkdir -p /var/www/geosciplot
```

## 步骤 ⑥：站点文件上服务器【你来做】

在你的 Windows 机器上（Git Bash），把构建产物推上去：

```bash
cd /e/AAAproject/GeoSciPlot
python scripts/build_site.py            # 生成 site/
cd site
rsync -avz --delete ./ root@47.98.133.104:/var/www/geosciplot/
```
> 没有 rsync 的话：`scp -r out/* root@47.98.133.104:/var/www/geosciplot/`
> （或用 WinSCP 图形界面拖过去）

**以后每次加图**：管理界面发布（自动 git push）后，重复这条 rsync 即可。
也可以配一个 GitHub Action 自动 rsync（需要时告诉我）。

## 步骤 ⑦：核对占位数据【你来做，发布前必须】

`meta/titles.csv` 里的 **journal 和 published 是占位模拟数据**（按图面内容推断）。
正式发布前请逐条按原论文核对——标错期刊属于学术不端。

操作：Excel 打开 `meta/titles.csv` → 修正 journal / published 两列 →
`python scripts/prepare.py && python scripts/build_site.py` → 重新 rsync。
